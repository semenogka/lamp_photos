Программа для поиска похожих фотографий светильников по изображению, которое отправил юзер.
В основе лежит модель CLIP, которая анализирует визуальное и текстовое сходство между изображениями.

💡 Что умеет программа
🔍 Поиск похожих светильников по одной фотографии — находит визуально схожие модели.
🧠 CLIP-классификация — поиск основан на современных эмбеддингах, объединяющих визуальные и текстовые признаки.
🗂️ Большой датасет — собран более чем с 10 разных сайтов, чтобы охватить максимум разнообразия моделей.
🧩 Фильтры — позволяют уточнять результаты поиска по материалам, цветам, типам и другим параметрам.
🖥️ Интерфейс — удобное графическое приложение с наглядным выводом результатов.
🔒 Защищённость — весь код выполняется на стороне клиента, что делает невозможным (или крайне трудным) его декомпилирование или кражу.

⚙️ Технологии
CLIP — основа системы поиска по поиску похожих светильников.
PyQt — графический интерфейс для более удобной визуализации.
Кэширование эмбеддингов — для ускоренного поиска без повторного анализа изображений.
Обработка данных с разных источников — парсинг, нормализация и классификация изображений светильников.

🚀 Преимущества
Полная автономность — работает на стороне клиента, без обращения к внешним API.
Простота использования — просто загрузите фото и получите похожие модели.

🧩 Пример использования
Запустите приложение.
Выберите или вставьте изображение светильника.
Настройте фильтры (например, по цвету металла или типу абажура).
Получите список визуально похожих моделей с наглядным отображением.

Пограмма может быть недостаточно точной из за маленького датасета.
